# holaMundoPython
Proyecto de ejemplo usando el lenguaje Python

## Descripción de la tarea

Tarea de la UT01 - Introducción a la programación de Inteligencia Artificial.
El objetivo de esta tarea es crear una cuenta y repositorio de GitHub y, a su vez, ejecutar un archivo python en el que se muestre un mensaje 'Hola mundo' en pantalla. 

## Contenido de la tarea 

- README.md: Breve descripción de la tarea.
- hola.py: programa que muestra la frase 'Hola Mundo' por consola.
